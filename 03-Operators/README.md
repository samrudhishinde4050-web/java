# Operators in Java

## What is an Operator?

An operator is a symbol that performs an operation on one or more operands.

## Types of Operators

1. Arithmetic Operators
2. Assignment Operators
3. Relational Operators
4. Logical Operators
5. Unary Operators
6. Increment and Decrement Operators
7. Ternary Operator
8. Bitwise Operators

## Arithmetic Operators

+ Addition

- Subtraction

*  Multiplication

/  Division

%  Modulus
