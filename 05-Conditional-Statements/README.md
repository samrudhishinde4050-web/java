# Conditional Statements in Java

## What is a Conditional Statement?

Conditional statements are used to make decisions in a program.

Java provides the following conditional statements:

1. if
2. if-else
3. else-if
4. Nested if
5. switch

---

## Syntax of if

```java
if(condition){
    // code
}
```

## Syntax of if-else

```java
if(condition){
    // code
}else{
    // code
}
```

## Syntax of else-if

```java
if(condition){

}else if(condition){

}else{

}
```

## Syntax of switch

```java
switch(variable){

case 1:
    break;

case 2:
    break;

default:
}
```
