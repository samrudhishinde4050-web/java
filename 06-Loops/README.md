# Loops in Java

## What is a Loop?

A loop is used to execute a block of code repeatedly until a condition becomes false.

## Types of Loops

1. for loop
2. while loop
3. do-while loop
4. Nested loop

## for Loop Syntax

```java
for(initialization; condition; increment/decrement){
    // code
}
```

## while Loop Syntax

```java
while(condition){
    // code
}
```

## do-while Loop Syntax

```java
do{
    // code
}while(condition);
```

## Loop Control Statements

- break
- continue
