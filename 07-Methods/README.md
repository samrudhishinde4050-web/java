# Methods in Java

## What is a Method?

A method is a block of code that performs a specific task.

## Advantages

- Code Reusability
- Reduces Code Duplication
- Easy Maintenance
- Improves Readability

## Types of Methods

1. Predefined Method
2. User Defined Method

## Syntax

```java
returnType methodName(parameters){

    // code

}
```
