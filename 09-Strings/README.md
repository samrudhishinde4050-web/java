# Strings in Java

## What is a String?

A String is a sequence of characters used to store text.

Example:

```java
String name = "Samrudhi";
```

## Features

- Immutable
- Stored as objects
- Rich set of built-in methods

## Common Methods

- length()
- charAt()
- toUpperCase()
- toLowerCase()
- equals()
- equalsIgnoreCase()
- compareTo()
- contains()
- substring()
