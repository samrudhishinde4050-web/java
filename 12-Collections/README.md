# Collections Framework in Java

## What is Collection?

The Java Collections Framework provides classes and interfaces to store and manipulate groups of objects.

## Main Collection Types

### 1. List

- Allows duplicate elements
- Maintains insertion order

Examples:

- ArrayList
- LinkedList
- Vector
- Stack

### 2. Set

- Does not allow duplicate elements

Examples:

- HashSet
- LinkedHashSet
- TreeSet

### 3. Queue

Used to store elements that are processed in a particular order.

Examples:

- Queue
- PriorityQueue

### 4. Map

Stores data in key-value pairs.

Examples:

- HashMap
- LinkedHashMap
- TreeMap

## Important Concepts

- Adding elements
- Removing elements
- Searching elements
- Sorting elements
- Traversing collections
- Iterator
- Comparable
- Comparator
