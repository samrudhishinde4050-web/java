# Generics in Java

## What are Generics?

Generics allow us to write classes, interfaces, and methods that can work with different data types while providing compile-time type safety.

## Example

```java
ArrayList<String> names = new ArrayList<>();
```

Here:

- `ArrayList` is a generic class.
- `String` is the type parameter.

## Advantages

- Type Safety
- Code Reusability
- Avoids unnecessary type casting
- Errors are detected at compile time
