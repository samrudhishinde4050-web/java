# File Handling in Java

File Handling is used to create, read, write, update, and delete files.

## Common Classes

- File
- FileReader
- FileWriter
- BufferedReader
- BufferedWriter

## Common Operations

1. Create a file
2. Write data
3. Read data
4. Append data
5. Get file information
6. Delete a file

## Advantages

- Store data permanently
- Read existing files
- Write data to files
- Manage application data
