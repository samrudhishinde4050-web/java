# Multithreading in Java

Multithreading allows a Java program to execute multiple tasks concurrently.

## What is a Thread?

A thread is a lightweight unit of execution within a program.

## Ways to Create a Thread

1. Extending the Thread class
2. Implementing the Runnable interface

## Important Thread Methods

- start()
- run()
- sleep()
- join()
- getName()
- setName()
- getPriority()
- setPriority()

## Important Concepts

- Thread lifecycle
- Multiple threads
- Thread priority
- Synchronization
- Race condition
