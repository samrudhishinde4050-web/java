# JDBC in Java

JDBC stands for **Java Database Connectivity**.

It is used to connect Java applications with databases.

## JDBC Workflow

```text
Java Application
       ↓
JDBC Driver
       ↓
Database
```

## Main JDBC Classes and Interfaces

- DriverManager
- Connection
- Statement
- PreparedStatement
- ResultSet

## CRUD Operations

### Create
Insert new data.

### Read
Retrieve existing data.

### Update
Modify existing data.

### Delete
Remove data.

## JDBC Steps

1. Load/Register Driver
2. Create Connection
3. Create Statement
4. Execute SQL Query
5. Process Result
6. Close Connection
