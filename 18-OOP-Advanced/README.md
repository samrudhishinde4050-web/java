# OOP Advanced Concepts in Java

Object-Oriented Programming allows Java programs to be designed using objects and classes.

## Main OOP Concepts

1. Inheritance
2. Polymorphism
3. Abstraction
4. Encapsulation

## Additional Concepts

- Method Overriding
- `this` keyword
- `super` keyword
- Abstract Class
- Interface
- Upcasting
- Downcasting
- `final` keyword

## Inheritance

Inheritance allows one class to acquire properties and methods of another class.

## Polymorphism

Polymorphism means "many forms".

Types:

- Compile-time polymorphism
- Runtime polymorphism

## Abstraction

Abstraction hides implementation details and shows only essential functionality.

## Encapsulation

Encapsulation wraps data and methods together and protects data using access modifiers.

## Interface

An interface defines a contract that implementing classes must follow.
