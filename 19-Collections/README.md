# Java Collections Framework

The Java Collections Framework provides classes and interfaces for storing and manipulating groups of objects.

## Main Collection Types

### List

Allows duplicate elements and maintains insertion order.

Examples:

- ArrayList
- LinkedList
- Vector
- Stack

### Set

Does not allow duplicate elements.

Examples:

- HashSet
- LinkedHashSet
- TreeSet

### Map

Stores data in key-value pairs.

Examples:

- HashMap
- LinkedHashMap
- TreeMap

## Important Interfaces

- List
- Set
- Map
- Queue
- Iterator
- ListIterator

## Sorting

Java provides:

- Comparable
- Comparator

## Collection Hierarchy

```text
Collection
│
├── List
│   ├── ArrayList
│   ├── LinkedList
│   └── Vector
│
├── Set
│   ├── HashSet
│   ├── LinkedHashSet
│   └── TreeSet
│
└── Queue

Map
│
├── HashMap
├── LinkedHashMap
└── TreeMap
```
