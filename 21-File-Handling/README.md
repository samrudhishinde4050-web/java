# Java File Handling

File Handling in Java is used to create, read, write, update, and delete files.

## Main Classes

- File
- FileReader
- FileWriter
- BufferedReader
- BufferedWriter

## Operations

1. Create a file
2. Write data
3. Read data
4. Get file information
5. Delete a file

## File Class

The `File` class is used to create and manage information about files and directories.

## FileReader

`FileReader` is used to read character data from a file.

## FileWriter

`FileWriter` is used to write character data to a file.

## BufferedReader

`BufferedReader` provides efficient reading of text.

## BufferedWriter

`BufferedWriter` provides efficient writing of text.
