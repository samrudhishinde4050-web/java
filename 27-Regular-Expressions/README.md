## 🔹 What is Regular Expression?

A **Regular Expression (Regex)** is a sequence of characters used to define a search pattern.

Regex is commonly used for:

- Data validation
- Searching text
- Finding patterns
- Replacing text
- Form validation

Example:

```java
String pattern = "[0-9]+";
