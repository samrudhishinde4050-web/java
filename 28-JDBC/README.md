# ☕ Java JDBC (Java Database Connectivity)

This folder contains examples and practice programs for **JDBC (Java Database Connectivity)**.

JDBC is used to connect a Java application with a database such as MySQL and perform database operations like INSERT, SELECT, UPDATE, and DELETE.
